# Nortropic Runtime

A runner for accepted, bounded development tasks using existing AI executors.
Runtime v0.1 is **not yet delivered**.

Start with [the current plan](docs/plan.md), which contains the resumption point,
verified results, limitations, and next action. Read the [mandate](docs/UPPDRAG-NORTROPIC-RUNTIME.md)
and [decisions](docs/decisions.md). Shared executor instructions are in `AGENTS.md`.

Only explicit dependencies and verified commands will be added here. Installation
or standalone model replies do not count as an accepted Runtime delivery.
